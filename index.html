우리집 알림장 개인정보처리방침

Android 앱 「우리집 알림장 - 가족의 기한과 일정을 한곳에」 · 시행일 2026년 9월 22일 (앱 이름 변경 반영)

  • 회원가입이 없고, 개발자가 운영하는 서버도 없어요.

  • 광고, 사용 분석, 위치 정보를 쓰지 않아요.

1. 처리하는 정보

앱에서 직접 입력한 다음 정보를 기능을 제공하는 데에만 사용해요.

  • 관리 대상의 이름·종류·아이콘·색 (예: 나, 우리차, 우리집)
  • 기한 항목의 제목, 기한과 준비 시작일, 해야 할 일, 체크리스트, 메모
  • 처리 기록(처리한 날짜, 입력한 경우 비용과 메모)
  • 알림 시각, 글자 크기 같은 앱 설정

실명이나 가족관계는 입력하지 않아도 되며, 주민등록번호·여권번호·운전면허번호·비밀번호·신분증 사진은 입력받지 않아요.

2. 저장 위치와 보관 기간

모든 정보는 이 휴대폰의 앱 전용 저장공간에만 저장돼요. 개발자는 이 정보를 받거나 볼 수 없어요.

정보는 사용자가 앱에서 지우거나 앱을 삭제할 때까지 보관되고, 앱을 삭제하면 함께 지워져요.

이 앱의 데이터는 Google 드라이브 자동 백업이나 기기 간 이전에 포함되지 않아요.

3. 제3자 제공과 외부 전송

입력한 정보를 제3자에게 제공하거나 외부 서버로 보내지 않아요. 앱에는 인터넷 권한이 없어요.

다만 사용자가 직접 다음 기능을 쓸 때에만 사용자가 고른 곳으로 정보가 전달돼요.

  • 공유: 고른 일정을 글로 만들어 휴대폰의 공유창으로 보내요. 받는 앱과 사람은 사용자가 직접 골라요. 메모는 기본으로 빠져 있어요.
  • 백업 파일: 사용자가 고른 위치에 파일(JSON)로 저장하거나 고른 앱으로 보내요. 파일에는 대상 이름, 기한, 처리 기록, 메모, 설정이 들어 있으며 암호화되지 않으니 믿을 수 있는 곳에 보관해 주세요.

4. 사용하는 권한

  • 알림: 기한과 준비 시작일을 이 휴대폰에서 알려드리기 위해 사용해요. 허용하지 않아도 기한 저장과 조회는 할 수 있어요.
  • 부팅 완료 수신: 휴대폰을 다시 켰을 때 예약한 알림을 다시 등록하기 위해 사용해요.

알림은 휴대폰 안에서 예약되며, 알림 내용을 외부로 보내지 않아요. 설정에서 잠금 화면 알림에 이름과 항목명을 숨길 수 있어요.

5. 광고와 분석

현재 버전에는 광고, 사용 분석 도구, 추적 기술이 없어요. 앞으로 광고를 넣더라도 입력한 이름·기한·메모를 광고나 분석에 쓰지 않으며, 이 방침을 먼저 고쳐 알려드릴게요.

6. 정보 삭제

앱에서 항목이나 대상을 삭제하면 휴대폰에서 지워져요. 모든 정보를 지우려면 앱을 삭제하거나 휴대폰 설정에서 앱 데이터를 삭제해 주세요. 직접 만든 백업 파일은 사용자가 따로 지워야 해요.

7. 아동의 개인정보

이 앱은 아동을 대상으로 하지 않으며, 아동으로부터 개인정보를 수집하지 않아요.
